Printer is Not Printing

Summary

Steps to resolve printing issues

Body

Issue/Question

Printer is not printing

I am not able to print

Error: memory is low. job cancelled

Environment

  • Windows 7
  • Windows 10

Cause

Multiple Causes

Resolution

Note: For problems printing to a network printer see Unable to Print to Network Printer

  1. Check USB Cable to ensure it is plugged in correctly and securely
  2. Restart printer
  3. Restart computer

Clear the print queue via control panel

  1. Open Control Panel
    1. Click 
    2. Type Cont
    3. Press Enter or Click Control Panel
  2. Click View Devices and Printers (under Hardware and Sound)
  3. Right Click the printer 
  4. Click See what's printing
  5. Click Printer
  6. Select Cancel All Documents
  7. Restart printer
  8. Restart computer

Clear the print queue via command prompt

  1. Click
  2. Type Command
  3. Right click Command Prompt
  4. Click Run as administrator
  5. Type net stop spooler
  6. Press Enter
  7. Type del %systemroot%\System32\spool\printers\* /Q
  8. Press Enter
  9. Type net start spooler
  10. Press Enter
  11. Restart printer
  12. Restart computer

ITS STAFF ONLY

  1. Check network connection 
  2. Verify Vlan of the port
  3. Reinstall USB Printer
  4. Reinstall Network Printer
  5. Installing Toshiba Copier Drivers
Please contact the Service Desk if you need further assistance
